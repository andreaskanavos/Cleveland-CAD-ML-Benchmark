# Dataset

This directory contains the processed Cleveland subset of the UCI Heart Disease dataset used in the accompanying analysis.

- File: `processed.cleveland.data`
- Original dataset: UCI Machine Learning Repository, *Heart Disease*
- Dataset authors: Andras Janosi, William Steinbrunn, Matthias Pfisterer, and Robert Detrano
- DOI: `10.24432/C52P4X`
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Original sample size: 303 records
- Analytic sample used by the workflow: 297 complete records after exclusion of six records with missing values

The dataset is third-party material. The repository's MIT License applies to the code and documentation, not to the dataset. Users should cite the original UCI dataset when reusing the data.
